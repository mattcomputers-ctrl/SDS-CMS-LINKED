# SDS Content Audit — field inventory
_Companion to [sds-content-audit.md](sds-content-audit.md). One row per rendered field, as classified by the section sweep and checked by two verification lenses. 'Same for all' = the printed text is identical on every SDS (language aside) unless a per-FG override exists. Rows marked ✗ in 'Verified' were refuted by verification (a real data path exists); see the main document's Appendix A._

## 1 — Identification
